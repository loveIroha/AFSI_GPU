# 预加载左室的短程耦合 IB 单因素对照（0.17.0）

0.16.0 的冻结位置诊断发现，原有 IB 核的节点速度对格点位置敏感；固定物理宽度的核改善了该诊断，而直接弱式载荷改善了配对功率恒等式。这些结论不能直接外推到耦合轨迹。因此本轮保持相同预加载固体、流体盒、Chorin 压力校正、固体力滞后、给定压力时程、时间步和固体网格，只改变 IB 核宽度与有限元载荷路径。

运行正式对照：

```bash
conda activate afsi-torch
python -m pip install -e ".[test,geometry]"
CUDA_VISIBLE_DEVICES=0 python -m pytest -q
CUDA_VISIBLE_DEVICES=0 python validation/compare_coupled_ib.py \
  --preload results/lv_equilibrium --device cuda \
  --fluid-levels 6 12 18 --steps 20 \
  --output results/coupled_ib_factors
```

先确认 `pytest` 的 CUDA 测试确实执行且全部通过，再运行正式对照。`CUDA_VISIBLE_DEVICES=0` 指定使用第一张 RTX 4090；CPU-only 环境会跳过 CUDA 测试，不能把这种结果当作目标 GPU 验证。

默认每轴 6/12/18 个 Q2 流体单元，每步 `5e-5 s`，运行 20 步至 `1 ms`；原腔压 `0.20 mmHg`，短程扰动目标 `0.22 mmHg`。固定核的物理宽度为 `1 cm`。因为本诊断的整数膨胀核必须保持零次和一次矩，所选网格对应膨胀倍数 1/2/3；在 6³ 上固定核与原核完全相同。每档流体网格的四个方法为：

| 方法 | 核宽度 | 有限元流体载荷 |
| --- | --- | --- |
| `native_density` | 原四点核，随网格间距缩小 | 原密度路径 `M_f Hᵀg/ΔV`，生产基线 |
| `fixed_density` | 固定 1 cm | 原密度路径，仅改变核 |
| `native_dual` | 原四点核 | 直接弱式载荷 `Hᵀg`，仅改变载荷 |
| `fixed_dual` | 固定 1 cm | 两因素同时改变，用于观察交互 |

所有替代方案都是**诊断方法**，生产默认仍是 `native_density`。输出 `report.json`、每组逐步历史和 `last_accepted.npz`。报告含相邻流体网格响应对比、同一网格相对生产基线的响应差、线性残量、流固配对功率差、格点功率恒等式、最小 `det(F)` 和流体散度。`completed=true` 只表示本轮算例完成，不意味着网格收敛或可进行完整生理周期。`dual` 的配对功率为零差是代数性质，不能单凭它判定模型正确。报告中的相对差会在基准响应接近零时记为 `null`，须看绝对差与更强的加载基准。

本轮仍改变流体网格而保持固体网格和时间步不变；固定核与原核是不同的正则化模型，不能把两种方法之间的差解释成同一离散的收敛误差。下阶段应对能保持同一物理问题的制造解或基准流场做独立检验，检查外壁距离影响，并进行流体、固体、时间步联合加密；在这些通过前，不宣称完整周期已验证。

## 本地 CPU 先导结果

在旧的本地预加载检查点上，6³/12³、8 步（0.4 ms）四组共 8 个轨迹均完成，最小 `det(F)` 为 0.999189，最大线性残量/容差为 0.992。6³ 时固定核膨胀倍数为 1，所以固定核与原核的结果完全相同。6³→12³ 的节点增量位移相对差为：原核+密度 72.8%、固定核+密度 119.5%、原核+直接弱式 53.9%、固定核+直接弱式 18.3%。四组均未通过 5% 筛选；其中较小的 18.3% 也不能证明其物理正确。腔体积响应量级很小，须同时检查绝对差。完整先导报告见 [数值记录](coupled-ib-pilot-results-0.17.0.json)；其中 `snapshot` 指向未随仓库提交的本地 `results/` 文件。

这个旧 CPU 检查点的 SHA256 是 `81ffd2ba26b0aabec58d59c0dc45b70e6179348b77cb41e7568b044ba73a8311`，与用户 RTX 4090 诊断所用检查点 `f1b21532517fc0c5da41326c31a873fbfc329793a98d368223e7904f3d74fc09` 不同；不能把两者逐项数值当作同一初始条件比较。正式 GPU 对照应直接使用目标机上的 `results/lv_equilibrium`，先核对其检查点哈希。

本地完整回归：**162 passed、98 CUDA skipped、1 warning**。这不代替目标 RTX 4090 上的完整 GPU 回归。

## RTX 4090 正式对照结果

用户提供的[完整 GPU 报告](coupled-ib-gpu-results-0.17.0.json)中，12 组 6³/12³/18³、20 步（1 ms）轨迹全部完成，检查点哈希为 `f1b21532517fc0c5da41326c31a873fbfc329793a98d368223e7904f3d74fc09`。原核+密度路径的 12³→18³ 腔体积/最大增量位移/节点位移向量差为 62.2%/59.2%/74.5%；固定核+直接弱式路径为 3.6%/3.5%/3.3%，但其 6³→12³ 节点位移差仍为 18.9%。这只是相邻网格筛选的结果，不能证明替代方法正确。报告没有 pytest 计数。[0.18.0 独立弱式参考](IB_WEAK_REFERENCE.md)表明，直接弱式路径没有逼近固定物理核对应的 Q2 连续弱式载荷，故目前不应改用该路径作为生产方法。

# 固定物理宽度 IB 力的独立有限元弱式参考（0.18.0）

0.17.0 的 RTX 4090 报告完成了 12 条预加载左室短程轨迹。在 12³→18³ 的 1 ms 对照中，原核+密度载荷的腔体积/最大增量位移/节点位移向量差为 62.2%/59.2%/74.5%；固定 1 cm 核+直接弱式载荷为 3.6%/3.5%/3.3%。后者仅在这一对网格通过预设的 5% 筛选，6³→12³ 节点位移差仍为 18.9%；该筛选本身不验证替代离散的物理正确性。[GPU 原始报告](coupled-ib-gpu-results-0.17.0.json)保留全部历史和检查点哈希。

本轮以**同一个固定物理问题**作独立参考：在厘米制 Q2 流体盒内，把单个给定节点力 `g` 用物理宽度 `ε=1 cm` 的三维 Peskin 核正则化。NumPy 标量核和 Gauss 积分直接计算

`b_i^ref = ∫_Ω N_i(x) g δ_ε(x-X) dx`，

不调用 PyTorch IB 散布或 Q2 质量矩阵组装。积分在每个核分段点分割，逐轴使用 32 点 Gauss 规则；积分参考满足合力与一次矩，32/64 点积分的相对差在四档网格上均小于 `2.3e-15`。相同位置和力下，比较 `Hᵀg`（直接弱式路径）与 `M_f Hᵀg/ΔV`（密度路径）对该参考的向量相对差。由于 `ε=m h` 且 `m` 是整数，`Hᵀg/ΔV` 正是正则化连续力密度在 Q2 速度节点上的取样；乘以一致质量矩阵后形成相应的有限元弱式载荷。

```bash
git pull --ff-only
conda activate afsi-torch
python -m pip install -e ".[test,geometry]"
CUDA_VISIBLE_DEVICES=0 python -m pytest -q
CUDA_VISIBLE_DEVICES=0 python validation/verify_ib_weak.py \
  --device cuda --preload results/lv_equilibrium \
  --output results/ib_weak_reference/report.json
```

默认在 6³/12³/18³/24³ 比较同一力的弱式载荷。脚本还在**同一 Q2 节点间距 0.5 cm、同一 IB 格点相位**下，将 12 cm 流体盒扩至 18 cm，分别对单点力和同一预加载左室的增量腔压力作一次 Chorin/参考 Schur 投影。脚本逐点检查两个盒子的 IB 支撑节点坐标和权重相同，因此盒子对照不会把网格间距/相位误差混入边界距离影响。报告 `completed=true` 只表示这些独立验证完成，不表示任何耦合方案获得完整周期验收。

## 本地 CPU 先导结果

| Q2 单元/轴 | 直接 `Hᵀg` 对积分参考 | 密度路径 `M_f Hᵀg/ΔV` 对积分参考 |
| ---: | ---: | ---: |
| 6 | 45.06% | 10.24% |
| 12 | 48.95% | 2.21% |
| 18 | 50.54% | 0.63% |
| 24 | 51.22% | 0.40% |

因此，**固定宽度核下的直接 `Hᵀg` 虽满足离散代数配对功率，却没有逼近此连续正则化力的 Q2 弱式载荷**。当前密度路径的该项误差随网格加密下降。这个对照否定了“功率配对恰为零，所以应直接替换为 `Hᵀg`”的推断，但只覆盖所定义的固定宽度正则化力；它不证明原生产轨迹已经收敛，也不排除其他定义的耦合模型。

同一格距的单点边界试验中，12 cm→18 cm 盒子的 Chorin 节点速度差为 0.38%。**同一预加载左室增量力**却明显不同：密度路径的盒子差为 **16.67%**，直接载荷路径为 **2.11%**；密度路径的 Chorin/Schur 节点速度差在两盒中分别为 **25.64%/21.72%**，直接路径为 **2.68%/2.54%**。这说明单点结果不能代表整个左室力分布，也表明在物理参考更一致的密度路径上，外边界和投影仍是不可忽略的影响因素。数值见[完整本地报告](ib-weak-reference-results-0.18.0.json)。本地左室对照使用旧 CPU 检查点 `81ffd2ba26b0aabec58d59c0dc45b70e6179348b77cb41e7568b044ba73a8311`；用户 GPU 耦合报告的检查点为 `f1b21532517fc0c5da41326c31a873fbfc329793a98d368223e7904f3d74fc09`，两者不能逐项等同。

本阶段没有重新求解预加载平衡，也没有启动完整周期。下一步应**优先保留对该连续参考显示一致性的密度载荷**，在目标 GPU 检查点上重做等格距盒子与 Chorin/Schur 对照，并检验更大流体域是否降低 16.67% 的盒子影响。之后研究与密度载荷配对的有限元插值：若散布右端为 `Sg=M_f Hᵀg/ΔV`，则代数功率对偶的插值应为 `Ju=H M_f u/ΔV`。这是待验证的候选离散，须先检查常量场、仿射场与正则化连续插值的一致性，再做固定核宽度下的时间步、流体和固体联合加密及短程耦合对照。

# 0.26.0 RTX 4090：CSR 左室周期结果

用户提供的 [`report.json`](lv-cycle-csr-gpu-report-0.26.0.json) 与 801 行 `history.csv` 显示：运行状态 `completed`，无续算，接受全部 16000 步，达到 0.8 s。运行设备为 RTX 4090、PyTorch 2.14.0+cu130，`backend=csr`，`check_every=8`。时间步、24³ 流体盒、生成的 616 单元固体网格、材料和载荷均与[旧版 0.25.0 报告](lv-cycle-gpu-report-0.25.0.json)一致。区别在于固定流体算子 CSR、分组收敛检查和诊断采样；因此耗时差反映这组改动的总效果，不能拆分给单一优化。

| 指标 | 0.25.0 积分算子 | 0.26.0 CSR | 变化 |
| --- | ---: | ---: | ---: |
| 报告内耗时 | 6446.105 s（107.435 分） | 1959.722 s（32.662 分） | 3.289 倍吞吐 |
| 平均每步 | 0.40288 s | 0.12248 s | 减少约 69.6% |
| PyTorch CUDA 峰值已分配 | 1.222 GiB | 1.857 GiB | 增加 0.635 GiB |
| 终点腔容积 | 153.023494510872 mL | 153.023494510872 mL | 报告精度内相同 |
| 终点最大流速 | 92.903727556585 cm/s | 92.903727556592 cm/s | 差约 7.2×10⁻¹² cm/s |

新 `history.csv` 的 801 行覆盖 0–16000 步，每 20 步一次，步号单调且数值字段均有限。旧版仅在仓库存档了 12 个选定相位的摘要；逐相位比较中，腔容积最大绝对差为 **1.42×10⁻¹³ mL**，最小 det(F) 最大绝对差为 **2.84×10⁻¹⁴**，流速最大绝对差为 **1.36×10⁻¹¹ cm/s**。这表明已保存的可比时点在浮点精度内一致；不能据此声称旧版所有 801 个采样点都已核对。新历史原文件 SHA-256 和关键时点保存在[相位摘要](lv-cycle-csr-gpu-phase-0.26.0.json)。

报告摘要中的最小 det(F) 从旧版 0.3869517086 变为新版 0.3869529745，是**统计口径变化**：旧版逐步诊断，新版只在采样步计算该极值。两版在共同的 0.651 s 采样点均约为 0.3869529745。最大线性迭代数 143→144 则与每 8 次检查收敛、检查期间冻结递推有关；两版报告的真实残差比值仍低于 1。

加速没有改变原轨迹中的物理解释边界：0.5 s 与 0.8 s 的规定载荷相同，腔容积仍分别约为 131.25 与 153.02 mL；0.8 s 末最大流速仍约 92.90 cm/s。首个周期尚未建立周期稳态，空间/时间收敛和流体/IB 通量仍待研究。PyTorch 的峰值已分配显存不是整卡峰值占用；也不能将本次 24³ 的占用按比例外推至更密 CSR 网格。下一档建议先单独测试 32³ 流体盒，保持固体网格和时间步不变，记录启动峰值显存、每步时长以及物理量差异。

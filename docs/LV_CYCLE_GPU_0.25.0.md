# 0.25.0 生成理想左室：RTX 4090 首个 0.8 s 周期

用户提供的 [`report.json`](lv-cycle-gpu-report-0.25.0.json) 和 801 行 `history.csv` 表明：运行状态为 `completed`，无续算，接受全部 16000 步，达到 0.8 s。报告内计算耗时 6446.1 s（107.4 分钟）；用户记录总墙钟约 110 分钟，平均约 0.403 s/步。PyTorch 报告的 CUDA 峰值已分配显存约 1.22 GiB；这不是整卡峰值占用。使用 PyTorch 2.14.0+cu130 和 RTX 4090。

本次为生成椭球左室、1276 个固体节点和 616 个四面体单元；背景流体盒为 12 cm、每轴 24 个单元，Q2 速度节点间距 0.25 cm；时间步 `5e-5 s`。初始状态是**未加载参考构形**，腔容积 82.758 mL。0–0.2 s 充盈至 8 mmHg，0.2–0.5 s 保持，0.5–0.8 s 施加规定的收缩压力与主动张力脉冲。此算例使用规定的内膜牵引压力，而非由闭环循环或瓣膜流动计算腔压。

完整记录中的最小 det(F) 为 0.38695，保持正值；最大 Courant 数为 0.026，最大节点每步位移/流体速度格距为 0.00656，所有报告的线性求解残量比值小于 1。这些指标说明本次推进没有因单元翻转、给定步长限制或线性求解器失败而中止；它们不证明空间/时间收敛或物理真实性。

**最需要解释的是末态和收缩期响应。** 0.5 s 和 0.8 s 的规定载荷同为 8 mmHg、主动张力为零，腔容积却分别是 131.251 和 153.023 mL（相差 21.772 mL，约 16.6%）。末端流速 92.90 cm/s 是整段最大值，说明仍有显著瞬态；不能把末态称为周期稳态。收缩段腔容积在约 0.593 s 达到 163.137 mL，0.7 s 降至 109.963 mL，又在约 0.78 s 升至 162.445 mL。这个往复变化需要结合腔面取向、体积计算、随动压力和主动应力方向、IB 功率/通量及流体边界进行定位，不能只凭曲线判定为生理射血。

壁体积在采样点最低约 100.960 cm³，相对初始 108.924 cm³ 减少约 7.3%；局部最小 det(F) 也降到 0.387。当前材料只使用体积惩罚，并非严格不可压，强压缩是否来自材料参数、压力与主动载荷耦合或离散误差仍待诊断。校正后散度的 L2 指标由 0.5 s 时 26.60 上升到 0.8 s 时 1030.39；这不是直接的腔内体积漏失量，需和整体通量、投影算子及网格敏感性一起判断。

下一轮应先用本次已有检查点与时序输出分析异常阶段，尤其核对 0.55–0.80 s 的固体腔容积、壁体积、流体净通量和 IB 能量交换；随后只在关键短窗口做空间/时间加密及分阶段计时。报告没有各求解阶段的耗时，不能仅凭 110 分钟总时长确定性能瓶颈。完整 `history.csv` 留在用户运行环境；[`phase` 摘要](lv-cycle-gpu-phase-0.25.0.json)记录 20 步采样、选定时点及原文件 SHA-256，便于核对。

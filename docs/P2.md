# 第二步：P2 四面体、数值积分与非线性节点力

## 范围与验收

本步将固体场从 P1 的每单元 4 个节点扩展到 P2 的 10 个节点，每节点 3 个当前坐标分量，共 30 个局部自由度。采用总拉格朗日描述，参考坐标 X 固定，未知量 x 是当前坐标。仍使用可压缩 Neo-Hookean 材料，便于独立核对解析结果。

参考网格目前必须是直边四面体，六个边节点位于边中点；当前构形允许二次变形。曲边参考几何会报错，不会被当成直边处理。prepare_p2 在积分前检查坐标、连接关系、退化程度及边中点顺序。

## 形函数与积分

参考四面体顶点为 (0,0,0)、(1,0,0)、(0,1,0)、(0,0,1)。以 L0=1-r-s-t、L1=r、L2=s、L3=t 表示重心坐标：

$$N_i=L_i(2L_i-1),\qquad N_{ij}=4L_iL_j.$$

本地节点顺序为 `v0,v1,v2,v3,e01,e02,e03,e12,e13,e23`。参考形函数导数经过逆几何 Jacobian 映射到物理参考坐标：

$$\nabla_XN_a=(\nabla_\xi N_a)D^{-1},\qquad D=[X_1-X_0,X_2-X_0,X_3-X_0].$$

形函数、导数、积分权重在预处理时计算并保留在目标 device。默认使用 Duffy 变换的张量积 Gauss 积分，degree=4 有 64 个点，每单元物理权重为 `abs(det(D))*w_q`。

degree 表示保证精确积分的多项式总次数，不是单元阶次，也不是积分点数。对含 log(J) 的非线性能量，degree=4 不保证精确。测试比较 degree=2、4、6 与高阶参考值，检验积分误差减小。本积分规则以易验证为目标，点数尚未优化。

## 从能量到残量和切线

$$F_{eqiJ}=\sum_a x_{eai}\frac{\partial N_a}{\partial X_J}(q),\quad J=\det F,$$

$$W(F)=\frac{\mu}{2}(F:F-3)-\mu\log J+\frac{\lambda}{2}(\log J)^2,$$

$$E_h(x)=\sum_{e,q}w_{eq}W(F_{eq}),\qquad g=-\frac{\partial E_h}{\partial x}.$$

独立的解析路径为

$$P=\mu(F-F^{-T})+\lambda\log J\,F^{-T},\qquad
g_{ai}=-\sum_{e,q}w_{eq}P_{eqiJ}\frac{\partial N_a}{\partial X_J}(q).$$

单元积分使用 einsum，共享节点组装使用 index_add。这里 g 已是积分后的节点力；不除以质量矩阵，不额外乘节点体积。后续与 afsi 对接时必须保留这一含义。

可直接使用以下接口：

```python
import torch
from afsi_torch import solid
from afsi_torch.tetrahedron import promote_p1

# X1: (N,3) reference vertex coordinates; cells1: (E,4) int64.
# Move BOTH tensors to the same device before preprocessing.
X, cells = promote_p1(X1, cells1)
geometry = solid.prepare_p2(X, cells, degree=4)
x = X.clone()

solid.validate_deformation(x, geometry)  # Outside torch.func transforms.
energy = lambda y: solid.energy(y, geometry, mu=2.0, lam=5.0)
residual = torch.func.grad(energy)        # Internal residual R_int=+dE/dx.
g = -residual(x)                         # Force exerted by elastic solid.
direction = torch.ones_like(x)
_, K_direction = torch.func.jvp(residual, (x,), (direction,))
```

若后续求静力平衡，应构造 `R=R_int-f_external`，再施加边界条件和求解 `K*delta_x=-R`。本步只实现及验证内部残量和切线作用，尚未实现完整 Newton 迭代、外载或约束处理。

`validate_deformation` 只在积分点检查 det(F)>0；这不是对整个二次单元处处无翻转或全局单射性的证明。核函数不会截断负 J 来掩盖失效状态。

## 独立验证

- 完整 P2 多项式空间的函数值与梯度再现。
- 四面体单项式的解析积分 `i! j! k! / (i+j+k+3)!`。
- 多单元共享边去重、仿射变形及 P2 顶点内力的解析性质。
- 刚体运动零能量/内力，变形后叠加刚体旋转的客观性。
- 二次剪切 `x=(X0+alpha*X1^2,X1,X2)` 的 J=1，单位参考四面体总能量为 `mu*alpha^2/30`。
- 节点力与能量梯度、逐单元组装对照、有限差分、参考态和变形态切线作用。
- 非多项式能量的积分阶次收敛、单元局部反向编号、无效网格检查。
- GPU 可用时比较 CPU/GPU 的能量、力与切线。

可选 Basix 对照使用 Basix 独立制表，在相同积分点上由 NumPy 逐单元积分和组装，避免把两套不同的积分规则误当作实现差异。实测本地顺序到 Basix 0.10.0 列顺序映射为 `[0,1,2,3,9,8,7,6,5,4]`；脚本通过节点坐标推导映射，不在计算核中硬编码 Basix 约定。

仍需后续核对：DOLFINx 全局/局部及 blocked DOF 映射、afsi 实际积分规则、材料参数和纤维场、表面压力和基底约束。此步通过不意味着已经复现完整 afsi。

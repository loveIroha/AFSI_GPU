# 预加载左室的 IB 位置、功率与投影诊断（0.16.0）

0.15.0 的 RTX 4090、Linux CPU 和本地 CPU 均显示 8³→10³ 短程耦合增压响应差约 39%–65%。此脚本继续在固定预加载构形上识别可能原因，不修改生产耦合算法，也不重算非线性平衡。

```bash
git pull --ff-only
conda activate afsi-torch
python -m pip install -e ".[test,geometry]"
CUDA_VISIBLE_DEVICES=0 python validation/phase_power_ib.py \
  --study results/preloaded_ib_study --device cuda \
  --output results/preloaded_ib_phase
```

输入目录是上一阶段完整研究，需含 `report.json`、`frozen/diagnosis.json`、`frozen/solid_probe.npz`；加载器核对同一预加载检查点和时间步。输出 `report.json` 保存所有情况和对照。代码在相同 Q2/Q1 流体盒中，仅移动 **IB 相互作用点** 相对于速度格点的位置，施加固定的增压节点力，固体材料力和腔体积梯度保持不变。测量原位、沿 x 方向四分之一格距、半格距，以及三轴各半格距。12³ 和 18³ 上分别检查原四点核/固定物理宽度核、原密度载荷/直接弱式载荷，共 32 组。

每组记录核的常量与一次矩、固体速度、腔体积变化率、流固节点功率、格点功率、有限元弱式功率及实际求解残量。按照当前 AFSI 式路径，格点层面的力/速度是代数对偶，但 Q2 一致质量矩阵处理后的弱式载荷不一定与该格点功率相等。直接弱式载荷是**对照离散**，不能因为它在某项指标上更稳定就无验证地替换生产算法。

报告同时继承 0.15.0 固定位置试验中生产路径的 Chorin/Schur 固体速度差，用于区分压力投影的影响。位置、载荷和投影效应可能相互作用，数值不能简单相加，也不能单因某一列差异较大就断言该项是短程轨迹全部误差的唯一原因。

位置试验的主要限制：固定盒子内移动相互作用点也改变了它们到外边界的距离，因此测得的是**相对格点位置及边界距离的联合敏感性**，不是无限域或周期域的纯格点相位误差；它也不是完整耦合轨迹。真正判定生产方法是否需要修改，还需固定物理问题下的制造解或收敛基准，以及固体/流体联合加密。报告 `completed=true` 仅表示试验执行完成，不等于完整周期或网格收敛。

## 首次本地结果

32 组均完成，核零/一次矩和格点功率恒等式处于数值精度。12³ 原核+密度路径沿 x 半格距的腔体积变化率差约 0.007%，但固体节点速度向量差约 29.86%；三轴各半格距的节点速度差约 43.61%。18³ 三轴各半格距为 25.52%。固定 1 cm 核+密度路径的同项差降至 3.45%/2.53%。原密度路径在 12³/18³ 的 Q2 弱式功率差约 -0.0633/-0.1629 erg/s；已有 Chorin/Schur 投影的固体速度差约 24.25%/14.02%。这些值提示多个因素需要处理，但不证明它们相加等于 0.15.0 耦合轨迹的全部误差。[完整数值记录](phase-power-results-0.16.0.json)。

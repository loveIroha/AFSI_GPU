# 从收敛预加载启动 IB：0.14.0

本步骤将已有非线性固体平衡接入显式 IB 时间步。保留原始参考坐标 X、纤维/片层、材料与基底弹簧；当前坐标为预加载后的 x。不能将 x 重置为新的无应力参考网格。

## 运行

```bash
git pull --ff-only
conda activate afsi-torch
python -m pip install -e ".[test,geometry]"
CUDA_VISIBLE_DEVICES=0 python -m pytest -q
CUDA_VISIBLE_DEVICES=0 python examples/preloaded_lv.py \
  --preload results/lv_equilibrium --device cuda --output results/preloaded_lv
```

输入目录需同时包含上一步的 `report.json` 与 `last_converged.npz`。已经成功的预加载不需要重算。仅在没有预加载时，先运行 `examples/lv_equilibrium.py --device cuda`。旧版 0.13 检查点没有面标签，加载时仅用 Gmsh 恢复标签，并逐一核对原参考坐标和单元编号；不相符即拒绝，不做猜测映射、不重新求平衡。新版检查点带面标签和材料方向，加载无需重建网格。

输出 `results/preloaded_lv/report.json`、两组各自的 `last_accepted.npz`、`solid.pvd` 和 `fluid.pvd`；`--no-vtk` 可关闭可视化文件。检查点输出使用 CPU，计算张量随 `--device cuda` 放入 GPU。该 NPZ 是最后接受状态的诊断快照，尚未提供任意中途时间步的通用重启入口。

## 两组短时测试

| 项目 | 默认值 |
| --- | --- |
| 固体 | 复用已有 P2 网格；默认预加载网格 h=1.8 cm，554 节点、260 四面体 |
| 流体 | 12×12×12 cm 背景盒，每轴 6 个 Q2/Q1 单元 |
| 流体间距 | 单元边长 2 cm，Q2 速度格点间距 1 cm |
| 时间 | dt=5e-5 s，20 步，共 0.001 s |
| 保持组 | 原预加载腔压与张力保持不变 |
| 增压组 | 前半段保持，随后四分之一时段增加 0.02 mmHg，末四分之一保持目标值 |

原显式离散的载荷滞后保持不变：第 n 步用保存的 g_n，更新流体和固体位置，再以旧时刻 t_n 计算下一步节点力。报告逐步记录实际施加/下一步保存的规定腔压，不能把当前时刻的名义压力当作已经施加的压力。默认末段足以让目标 0.22 mmHg 实际进入时间步。

新入口 `ExplicitIBStepper.initialize_equilibrium` 在物理时刻零计算完整节点力，要求其范数不大于预加载报告的收敛容差，并保存实际小残余力；没有人为归零或减去初始力。使用全节点力检查，适用于这里带基底弹簧的 LV；不能将含未平衡支座反力的其他约束问题直接套用。原 `initialize` 的零力启动入口仍用于原回归。

加载器检查最终加载比例、收敛标记、材料/几何/单位一致性、构形有效性、重新计算的实际残量与最终诊断。仅修改 JSON 的成功标记不能绕过力平衡检查。反向对照把载荷恢复成从零加载，在现有 0.2 mmHg 预加载下产生约 2093 dyn 的不平衡力，并被新入口拒绝。

## 已验证范围

本地 CPU 完整回归 **155 passed、96 CUDA skipped**。已有预加载的保持组最大位移漂移 2.57e-15 cm、腔体积漂移 1.42e-14 mL；增压组最大增量位移 1.79e-7 cm、腔体积增加 9.46e-6 mL。所有流体线性求解的真实残量均在各自容差内。保持筛选阈值为位移 1e-8 cm、体积 1e-7 mL、速度 1e-6 cm/s；增压响应必须超过保持漂移的 100 倍且超过 1e-10 cm。它们是启动诊断阈值，不是网格收敛误差界。

**压力定义：** 当前腔压是固体内表面的给定随动牵引，已经包含在完整固体节点力里；背景 Chorin 压力和速度初值为零。保持实验验证的是这种给定牵引平衡的接续，没有重建 0.2 mmHg 的真实腔内流体压力场。不要再将同一规定压力重复作为流体载荷加入。图中的背景流体压力不能直接解释为生理左室腔压。

这一步不证明完整周期可用，也不解决已发现的 IB/流体网格敏感性。下一阶段用这个无明显启动冲击的预加载基线，比较流体网格、核宽、弱式载荷功率和压力投影，再进行时间/流固联合加密与延长运行。真实腔压初场、进出流/瓣膜或循环系统耦合仍需单独设计。

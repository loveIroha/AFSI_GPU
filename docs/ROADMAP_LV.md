# 从当前模块到生成椭球左心室的 PyTorch AFSI

目标：程序生成理想左心室的带壁厚、基底开口的三维椭球壳，固体采用 P2 四面体，背景流体采用规则六面体 Q2/Q1 速度/压力有限元；GPU 上完成固体力、IB 传递、流体计算和时间推进。CPU 可用于网格生成、一次性预处理与结果输出。算例不依赖用户提供的心室网格或纤维文件。

首版范围为无显式瓣膜、无完整循环系统模型的理想算例。内外半轴、截断平面、网格尺度、纤维角、压力/主动张力时程由配置给定，采用 cm–g–s 单位制。它用于数值方法验证，不直接等同于生理预测。

## 六个开发里程碑

从 0.5.0 的固体装配对照基线起分为六步。0.6.0 实现第 1 步，0.7.0 实现第 2 步（用户已反馈 131 项 CPU/GPU 全通过），0.8.0 实现第 3 步（用户已反馈 155 项 GPU 环境全通过），0.9.0 实现第 4 步的可运行基线；本版目标 GPU 验证仍需执行。0.10.0 已实现第 5 步的短程耦合基线；后续主要阶段是完整算例验收，包括长程稳定性、时间步/网格收敛、预条件性能和分裂误差。里程碑不表示一次提交或一天工作量，尤其流体求解与预条件可能需多轮迭代。

| 步骤 | 交付内容 | 通过标准 |
| --- | --- | --- |
| 1. IB 传递（已实现） | 四点 Peskin 插值/散布、积分节点力接口、随位置重建 stencil | 常量/线性再现，合力/力矩，瞬时功率一致，独立标量参照，CPU/GPU 对照 |

## 第 2 步的网格方案

使用 Gmsh 几何构造与体网格生成作为 CPU 预处理：外椭球减去内椭球，再按基底平面截断，得到带壁厚的心室壁体。程序直接提取生成的节点、四面体和面标签并转换为张量；可选写文件用于检查，但算例入口不读取预先存在的心室数据。

初版参考几何保留直边四面体，P2 边节点取中点，使其与当前固体核一致。几何边界是椭球的分片平面近似，需通过网格细化评估几何误差。不能把弧面投影后的曲边 P2 节点直接传给当前直边参考核。

纤维采用规则方法，根据跨壁位置插值螺旋角，并构造片层方向。心尖附近轴向坐标存在方向退化，需要单独验证和平滑处理。纤维插值后仍遵循现有离散：积分点上再计算 normal=cross(sheet,fiber)，避免导入路径无意改变本构。

腔体体积计算需要对基底开口作**仅用于测量的虚拟封口**；不能把用于算体积的封口误当成真实固体面并施加压力。运动基底的封口定义必须保持一致。压力所用 ENDO 法向是固体外法向，指向腔内。

## 最重要的后续难点

1. **流体线性求解与预条件。** 当前已有 Jacobi-PCG 的 PyTorch 求解基线；目标 GPU 验证和大规模性能验收尚待执行。规则背景网格使矩阵无关算子和几何多重网格具备条件，但需要实测验证；不能只把 PETSc 的矩阵转成 CUDA 张量就认为完成迁移。
2. **离散耦合一致性。** IB 的格点体积 dV、Q2 单元体积和一致质量矩阵是不同对象。原 afsi 的力密度路径与直接弱式节点载荷路径必须显式区分并验证，不能以一个局部功率测试替代完整能量检查。
3. **近不可压缩与显式更新。** Guccione 体积惩罚较大时会影响条件数和时间步，显式坐标更新的稳定性需要对照与时间步收敛，不能凭单步力正确保证长时间稳定。
4. **左室的开口与载荷定义。** 首版先明确背景边界、基底约束、规定压力和主动张力的角色；不能把规定腔压和流体求出的压力重复当作同一外载。真实进出流、瓣膜和 Windkessel 等循环模型属于后续扩展。

双 GPU 并行、自动微分贯穿整个心动周期、真实心室数据导入和完整生理标定不属于首版验收必需项。先完成可验证的单 GPU 理想左室，再按性能瓶颈扩展。

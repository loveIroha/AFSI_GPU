# 左室数值稳定性与加密研究（0.11.0）

本阶段建立可重复的时间步、流体网格、固体网格和模拟时长研究，保持 0.10.0 的物理方程、载荷斜坡、零力启动和滞后更新顺序。结论是：**能完成短程运行，但当前流体/IB 空间分辨率尚未通过响应敏感性检查，不能据此开始可信的完整心动周期。**

## 运行

```bash

conda activate afsi-torch
python -m pip install -e ".[test,geometry]"
CUDA_VISIBLE_DEVICES=0 python -m pytest -q
CUDA_VISIBLE_DEVICES=0 python validation/study_lv.py --device cuda --output results/lv_study
```

## 默认 11 组研究

| 研究 | 改变量 | 固定条件 |
| --- | --- | --- |
| 时间步 | 1e-4、5e-5、2.5e-5 s | T=0.001 s，流体 6³，固体 h=1.2 cm |
| 流体网格 | 每轴 6、8、10 个单元 | T=0.001 s，dt=1e-4 s，同一固体网格 |
| 流体网格复查 | 每轴 6、8、10 个单元 | T=0.001 s，dt=2.5e-5 s，同一固体网格 |
| 固体网格 | Gmsh 目标尺度 1.4、1.2、0.9 cm | T=0.001 s，dt=1e-4 s，流体 6³ |
| 时长延长 | 0.001、0.005、0.01 s | dt=1e-4 s，流体 6³，固体 h=1.2 cm |

共享基线不重复运行。时间步比较使用相同物理终止时刻，不能固定步数后把不同时刻的结果称为误差。仅改变流体网格或时间步时，程序缓存同一个固体参考网格与纤维，并核对坐标、拓扑及自由度编号后才做节点位移比较。

固体加密改变初始曲面几何和自由度，故只比较体积**变化量**、最大位移等标量，不直接相减不同网格的节点数组。体积响应的相对差以较细结果的 ΔV 为分母，而不是以约 83 mL 的初始体积为分母；响应接近零时返回 `inconclusive`，不伪造零误差。

## 输出与诊断

- `study.json`：运行环境、代码指纹、每组参数、全部历程、比较结果和限制。
- `summary.csv`：各组最终响应、最小 det(F)、散度、压力迭代数等。
- 各组目录中的 `report.json`、`history.csv`、`last_accepted.npz`：完整轨迹及最后接受状态。失败时保存失败类型、阶段、尝试步数；不自动修改 dt、载荷或求解容差。
- `study.png`：可选的时间步、网格和时长结果图。

观察量包括三步真实残量/停止阈值比、压力迭代数、局部散度 L2、外边界净通量、壁体体积、积分点 det(F)、位移、被动/弹簧能量和格点/有限元功率差。散度 L2 的 CGS 单位为 cm^(3/2)/s；外边界净通量近零不代表局部无散或腔体无泄漏。体积惩罚有限、腔体基底开口和虚拟测量封口，也使壁体体积漂移不能单独等价为腔体泄漏。

累计 `fe_minus_solid_work` 只是按时间步积分的两种功率差，不是完整能量平衡残量，不含所有黏性耗散、边界功和载荷时变项。CPU 计时含准备和输出，不用于宣称 GPU 加速。

## 下一步应解决的问题

优先定位流体网格敏感性，而非继续延长到完整周期：

1. 分开检查压力分裂误差、IB 核支撑宽度及固体/流体相对网格尺度；当前标准 Peskin 核随背景间距变窄，流体加密同时改变了平滑尺度。
2. 在时间误差足够小时做固体与流体联合加密；本轮分开加密只是敏感性研究，尚未进入已证明的渐近收敛区间。
3. 结合相同方程的独立参考和质量/能量诊断，再决定调整分辨率、耦合离散或压力投影。任何数学方法变更都需要单独说明和验证。

预加载、周期载荷、进出流/瓣膜条件仍未完成。自定义 CUDA 核可以优化性能，但不会自动解决这些数值误差；本轮不更换 IB 核或原 AFSI 的密度载荷路径。
